# AI 学习工作台

一个给学生用的每日学习清单。打开网页就能记下要做的事、勾选完成，进度会跟着变化。不需要安装、不需要账号，任务只保存在你自己的浏览器里。

## 怎么使用

1. 用浏览器打开这个网站（或直接打开仓库里的 `index.html`）。
2. 第一次打开会看到 3 条示例学习任务。
3. 在输入框写下新任务，点击「添加」，或按回车。空白内容不会被加入，输入框会在成功添加后清空。
4. 点任务左侧的勾选框，把它标为完成；再点一次可以改回未完成。
5. 顶部的进度来自当前清单：已完成数量 / 全部数量。全部完成后，页面会显示一句鼓励。
6. 刷新页面，任务还在。如果清单是空的，会看到一段提示。

## 开启 GitHub Pages

1. 打开本仓库的 **Settings**（设置）。
2. 左侧选择 **Pages**。
3. 在 **Build and deployment** 中，Source 选择 **Deploy from a branch**。
4. Branch 选择 **main**，文件夹选择 **/ (root)**。
5. 保存后等一两分钟。站点地址是：<https://butelebao7-max.github.io/Ai-student-workspace/>

## 文件

- `index.html`：页面结构
- `style.css`：样式
- `script.js`：任务列表、本地保存和进度

只用到浏览器自带的 HTML、CSS 和 JavaScript，没有框架，也不需要构建。
