# AI 学生工作台

一个帮助学生管理每日学习任务的静态小网站。打开网页就能用，不需要安装、不需要构建，也没有账号。

## 这个网站是做什么的

把今天要学的事情记在一份清单里：

- 查看当前的学习任务
- 在输入框写下新任务，点击「添加」或按回车加入清单
- 点任务前面的方框，标记为已完成；再点一次可以改回未完成
- 页面上方会显示已经完成了几项
- 全部完成后，会出现一句鼓励
- 刷新页面后，任务还在（保存在这台设备的浏览器里）

第一次打开、还没有保存过任务时，会放上 3 条示例学习任务。清单是空的时候，会显示一段提示。只输入空格不会被添加。

## 怎么使用

1. 用浏览器打开 `index.html`，或者打开启用 GitHub Pages 之后的网址。
2. 在输入框写下一项学习任务，点击「添加」，也可以按 Enter。
3. 做完一项，就点一下前面的方框。
4. 想取消完成，再点一次方框。

任务只保存在当前浏览器中。换一台设备、换一个浏览器，或者清除这个网站的数据之后，清单不会跟着走。

## 如何开启 GitHub Pages

1. 打开本仓库的 **Settings**。
2. 左侧进入 **Pages**。
3. 在 **Build and deployment** 中，Source 选择 **Deploy from a branch**。
4. Branch 选择 **main**，文件夹选择 **/ (root)**。
5. 保存后等一两分钟。页面会发布到：

https://butelebao7-max.github.io/Ai-student-workspace/

本项目只有 `index.html`、`style.css` 和 `script.js`，直接从仓库根目录发布即可。
